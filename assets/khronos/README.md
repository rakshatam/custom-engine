# Khronos Metal-Rough Spheres Sample

`MetalRoughSpheresNoTextures.glb` is a Khronos glTF Sample Asset used to exercise imported metallic/roughness factors and DXR reflection behavior.

- Upstream: https://github.com/KhronosGroup/glTF-Sample-Assets/tree/main/Models/MetalRoughSpheresNoTextures
- Sample catalog and attribution: https://github.com/KhronosGroup/glTF-Sample-Assets/blob/main/Models/Models.md

- Downloaded from the official KhronosGroup repository's `main` branch on 2026-10-16.

The sample is unchanged. The engine importer and renderer changes are maintained in this repository.
